1

L'Onglet Graphe : La Vision Macro de votre Campagne

Accessible d'un simple clic au centre de la barre supérieure (entre Éditeur, Timeline et Calendrier), la vue Graphe analyse instantanément toutes les liaisons [[wikilinks]] présentes dans l'ensemble de votre Coffre (Vault).

Sans Configuration

Dès que vous écrivez [[Nom]] dans une note, le lien se tisse automatiquement en arrière-plan sans action manuelle.

Navigation d'un Clic

Cliquer sur n'importe quelle sphère du graphe ouvre immédiatement la note correspondante dans l'Éditeur.

Détection des PNJ Isolés

Identifiez d'un coup d'œil les pistes de scénario orphelines qui ne sont raccordées à aucun lieu ni personnage.

2

Source des Données : Comment le Graphe se Remplit

Sur la capture, le coffre ne contient actuellement qu'une seule note (Bienvenue.md), c'est pourquoi le graphe est encore épuré. Pour le peupler, Grimoire analyse deux éléments :

🔗 1. Les Rétroliens Markdown

Lorsque vous écrivez dans Bienvenue.md : 

Le trésor de [[Karak-Azgal]] est sous la garde du [[Capitaine Barbe-Noire]].

Grimoire trace automatiquement deux liens reliant Bienvenue.md vers Karak-Azgal et Capitaine Barbe-Noire.

🎨 2. Les Types Frontmatter (Couleurs)

Si vous ajoutez en tête de note un tag de type, Grimoire colore le nœud automatiquement : 

---
type: pnj
---
  • • type: pnj / npc → Sphère Rouge
  • • type: lieu / location → Sphère Bleue
  • • type: quete / quest → Sphère Jaune
  • • Par défaut → Sphère Lore Grise
3

Le Bouton 🔄 : Actualisation & Synchronisation FTS5

Situé tout en haut à droite du canvas, le bouton 🔄 recharge immédiatement la base de données relationnelle SQLite de l'application. Si vous venez de créer ou supprimer plusieurs fichiers, un simple clic rééquilibre la simulation physique D3.js.

4

Contrôles de la Toile Interactive (Souris & Gestes)

🖱️
Molette de Souris

Zoom avant / zoom arrière progressif pour naviguer d'une vue d'ensemble jusqu'aux titres des fiches.

🖐️
Clic & Glisser (Pan)

Déplacez l'ensemble de la vue sans affecter l'équilibre des connexions.

🎯
Clic sur un Nœud

Ouvre instantanément le document correspondant dans l'Éditeur Markdown.
